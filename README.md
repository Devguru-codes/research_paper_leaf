# What Makes Medicinal Leaf Classifiers Transfer from Studio to Field?

This repository contains **all code, configurations, unit tests, run outputs and the LaTeX paper** for
a controlled study of studio-to-field transfer on the 30-species Medicinal Leaf Dataset, tested on
field photographs of 20 species (DIMPSAR). It also contains *sweep-valuation attention* (SVA), a
module we introduce and evaluate as part of the study. Every number in the paper is generated by the
scripts here from the run outputs stored in [`results/runs/`](results/runs).

- Paper (PDF): [`paper/main.pdf`](paper/main.pdf) · LaTeX source: [`paper/`](paper)
- Model code: [`src/models/`](src/models) · Unit tests (the proofs of the stated properties): [`tests/`](tests)
- Raw evidence for every run: [`results/runs/`](results/runs) · Statistics: [`results/summary/`](results/summary)

## Main findings

Raw field photographs, 20-way accuracy (%), ConvNeXt-T, 5 folds × 5 seeds (25 runs per model):

| Model (one ingredient added per row) | Raw field |
|---|---|
| Plain backbone (features averaged over the whole photo) | 33.6 |
| + mid-level feature branch, no mask (patch pooling) | 37.1 |
| + mask pooling (knows where the leaf is) | 41.1 |
| + localised pooling: slab-only attention | 45.7 |
| + localised pooling: strip pooling | 46.8 |
| + measured geometry: SVA | 47.4 |
| Global fusion of SVA's measurements (no localisation) | 33.5 |

- Clean in-domain accuracy is saturated (99.9–100%) for every model on the leakage-audited protocol.
- The gain has three parts: **mid-level features** +3.5 (n.s.), **leaf location** +4.0 (25/25 runs, Holm p = 0.001;
  vanishes once the background is whitened) and **localised pooling** +4.6 to +6.2 (strip: 25/25, Holm p = 0.002).
- **Measured geometry adds little if anything:** SVA vs strip pooling +0.5 (12/25), SVA vs slab-only +1.7 (16/25);
  global fusion is equivalent to plain within ±3 points (TOST).
- The gains hold **without rotation augmentation** (5 seeds) and **on top of strong background-compositing
  augmentation** (3 seeds; best model 55.2%).
- They are small on EfficientNet-B0 (3 seeds), absent on ViT-S, and irrelevant for the BioCLIP 2
  foundation model (81% without any module); a general self-supervised DINOv2 ViT-S reaches only 52%.
- **Not a tuning artefact:** at half and twice the backbone learning rate, strip pooling still beats plain by
  +13.5 and +8.4 points (5/5 folds each); plain's best rate reaches 35.3%.
- **Pre-registered replication on LeafSnap30** ([predictions](paper/preregistration_leafsnap.md), committed
  before any run; field leaves on plain paper, 30-way, 10 runs per model): plain 45.9%, strip 50.1%, SVA 49.5%.
  Three of four predictions hold: smaller total gain (strip +4.1, Holm p = 0.006), no leaf-location effect
  (+0.1), SVA equivalent to strip (−0.6, TOST); localisation +2.5 is not significant.

## Repository layout

```
src/                 all model, data and analysis code
  data/              dataset audit (duplicates, re-shots), masks, venation pseudo-labels, splits,
                     taxonomy, corruptions (MedLeaf-C), cue-conflict, topology edits
  models/            cubical_ect.py (valuation increments), esa.py (SVA and the pooling controls),
                     backbones.py, esformer.py (full model), baselines, mask_head.py (own leaf masker)
  train.py           training + all evaluation probes for one run
  evaluate.py        rotation, corruption, cue-conflict, topology-destruction and field-photo probes
  make_tables.py     collect all runs into tables
  stats.py           corrected resampled t-test, Holm, Wilcoxon / McNemar
  study_contrasts.py the pre-specified contrasts of the paper (+ two-way bootstrap)
  stats_all.py       all SVA-vs-control comparisons -> results/summary/stats_all.json
  make_figures.py    paper figures and LaTeX tables from the run outputs
  topo_matched.py    LPIPS-matched topology-destruction analysis
  field_analysis.py, vein_check.py, cost.py, make_paper_assets.py   appendix tables and figures
tests/               unit tests: Euler characteristic, telescoping, partition of unity, sharp limit,
                     closed forms, rotation equivariance, split leakage, mask pooling, augmentation
configs/             job specifications for every experiment (make_*_jobs.py generate them)
kaggle/              scripts that build, push and monitor the private Kaggle GPU kernels
paper/               LaTeX source, figures, bibliography and compiled PDF
results/runs/        outputs of every Kaggle run (metrics.json, eval_*.json, per-image
                     predictions preds_*.npz, per-sample probe CSVs, kernel logs, queue logs)
results/summary/     statistics, contrasts, cost, per-species and probe summaries used in the paper
data/audit/          dataset audit: index with duplicate / re-shot groups (no images)
data/audit_leafsnap/ the same for LeafSnap30, plus the field-photo index
```

## Reproducing

1. **Install** (Python 3.11): `pip install -r requirements.txt`
2. **Data** (not redistributed here, see [`data/README.md`](data/README.md)): download the
   *Segmented Medicinal Leaf Images* (Mendeley, DOI 10.17632/nnytj2v3n5.1) into `data/`, or point
   `MEDLEAF_RAW` to it.
3. **Audit and preprocess** (duplicate/re-shot grouping, masks, vein pseudo-labels):
   `python -m src.data.audit` writes `cache/` (set `MEDLEAF_CACHE` to change the location).
4. **Tests**: `python -m pytest tests`
5. **One run**, e.g. SVA on ConvNeXt-T, fold 0:
   `python -m src.train --set backbone="convnext_tiny" variant="slabstat" token="ap" fold=0 seed=0 evals='["crossdomain"]'`
   (model names: plain = `variant=plain`; mask pooling = `variant=maskpool`; strip = `variant=strip`;
   slab-only = `variant=esa token=none`; SVA = `variant=slabstat token=ap`; global = `variant=global token=ap`).
6. **All experiments** were run on Kaggle (2×T4) with `configs/make_main_jobs.py`,
   `configs/make_round2_jobs.py` … `configs/make_round5_jobs.py` and `kaggle/launch.py` / `kaggle/kqueue.py`.
7. **Tables, statistics and figures** from the stored outputs:
   ```
   python -m src.study_contrasts results/runs
   python -m src.study_contrasts results/runs leafsnap
   python -m src.stats_all results/runs
   python -m src.make_figures results/runs --out paper/figures
   ```
