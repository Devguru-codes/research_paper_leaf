# When Does Leaf Geometry Help? Sweep-Valuation Attention for Studio-to-Field Medicinal Leaf Identification

This repository contains **all code, configurations, unit tests, run outputs and the LaTeX paper** for
our study of *sweep-valuation attention* (SVA) on the 30-species Medicinal Leaf Dataset, with transfer
to field photographs (DIMPSAR). Every number in the paper is generated by the scripts here from the
run outputs stored in [`results/runs/`](results/runs).

- Paper (PDF): [`paper/main.pdf`](paper/main.pdf) · LaTeX source: [`paper/`](paper)
- Method code: [`src/models/`](src/models) · Unit tests (the proofs of the stated properties): [`tests/`](tests)
- Raw evidence for every run: [`results/runs/`](results/runs) · Statistics: [`results/summary/`](results/summary)

## What SVA does

A directional sweep partitions the leaf into ordered slabs (32 directions × 16 slabs). For each slab,
SVA measures how much **area** and **boundary length** of two weighted cubical complexes, the blade
mask and a learned venation field, enter the filtration there. Cell weights are conditioned on backbone
features. Each measurement becomes a token that cross-attends to the image patches of the same slab.
The module is differentiable and backbone-agnostic (`src/models/cubical_ect.py`, `src/models/esa.py`).

## Main findings (from `results/`)

| Raw field photos, 20-way accuracy (%) | ConvNeXt-T (5 folds × 3 seeds) | ViT-S/16 (5 folds) | BioCLIP 2 (5 folds) |
|---|---|---|---|
| Plain backbone | 33.5 | 60.4 | 81.4 |
| Global fusion of the same valuations | 33.7 | 58.6 | 81.3 |
| Strip pooling | 47.8 | 62.7 | 81.5 |
| Slab attention without valuations | 45.7 | **64.8** | 81.8 |
| **SVA (ours)** | **49.3** | 60.7 | 81.7 |

- Clean in-domain accuracy is saturated (99.9–100%) for every model on the leakage-audited protocol.
- With ConvNeXt-T, SVA improves studio-to-field transfer by +15.8 points (15/15 runs, p < 0.001).
  Trained **without rotation augmentation** it keeps this gain and beats strip pooling (+5.8) and
  slab-only attention (+5.2), winning 5/5 folds each.
- The gain disappears for ViT-S and for the BioCLIP 2 foundation model.
- Ablations: appearance-conditioned cell weights (−9.5 points without them) and a fine sweep (−6.3)
  drive the effect; restricting attention to the slab adds little (−1.1). Euler-characteristic tokens
  make models sensitive to holes in the blade (4.5× response) but transfer worse.


## Reproducing

1. **Install** (Python 3.11): `pip install -r requirements.txt`
2. **Data** (not redistributed here, see [`data/README.md`](data/README.md)): download the
   *Segmented Medicinal Leaf Images* (Mendeley, DOI 10.17632/nnytj2v3n5.1) into `data/`, or point
   `MEDLEAF_RAW` to it.
3. **Audit and preprocess** (duplicate/re-shot grouping, masks, vein pseudo-labels):
   `python -m src.data.audit` writes `cache/` (set `MEDLEAF_CACHE` to change the location).
4. **Tests**: `python -m pytest tests`
5. **One run**, e.g. SVA on ConvNeXt-T, fold 0:
   `python -m src.train --set backbone="convnext_tiny" variant="slabstat" token="ap" fold=0 seed=0 evals='["rotation","corruptions"]'`
   (model names: plain = `variant=plain`; global = `variant=global token=ap`; strip = `variant=strip`;
   slab-only = `variant=esa token=none`; SVA = `variant=slabstat token=ap`).
6. **All experiments** were run on Kaggle (2×T4) with `configs/make_main_jobs.py` and
   `kaggle/launch.py` / `kaggle/kqueue.py`.
7. **Tables, statistics and figures** from the stored outputs:
   ```
   python -m src.make_tables results/runs/main_cnx_s0
   python -m src.stats_all results/runs
   python -m src.run_conformal results/runs --out results/summary/conformal.csv
   python -m src.make_figures results/runs --out paper/figures
   ```
